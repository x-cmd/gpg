# `pub/` — ASCII-armored public keys

One file per published key, named `<handle>.asc` (lowercase,
ASCII-only, matches the `handle` column in
[`index.tsv`](../index.tsv)). The concatenated keyring
`keys.asc` is regenerated from these by the team on every
release commit.

## File shape

```text
pub/
  ├── <handle>.asc       # ASCII-armored export of one key (gpg --armor --export)
  └── keys.asc           # all-of-the-above concatenated, regenerated by the team
```

`keys.asc` is what most consumers import (one HTTP GET, one
`gpg --import`). The per-key files are kept so consumers can
import a single maintainer's key without dragging in everyone
else, and so a rotation only swaps the one affected file
(see [Key rotation](../CONTRIBUTING.md#key-rotation)).

## What's in an `.asc` file

A standard GnuPG ASCII-armored public key export:

```text
-----BEGIN PGP PUBLIC KEY BLOCK-----

mQINBF...m4...body...==gpg-base64-payload...
-----END PGP PUBLIC KEY BLOCK-----
```

The bytes between the markers are base64 of the OpenPGP packet
stream. They can be re-imported with `gpg --import <file>`,
`gpg --show-keys <file>` to inspect without importing, and
`gpg --list-packets <file>` to dump the packet structure for
debugging. None of these mutate the local keyring.

## Naming convention

`<handle>` follows the same identifier used in
`index.tsv` column 1 and in the team's other repos (handles
in the `x-cmd` monorepo, `x-cmd` website, etc.). Lowercase,
no spaces. If a handle needs to change for any reason, the
team updates `index.tsv` *and* renames the file in the same
release commit — the rename shows up as `R` (rename) in `git
log --diff-filter=R -- pub/`, which is the audit trail
consumers can use to track the change.

## Archive

When a key is rotated, the previous file moves to
`pub/archive/<handle>.<created-date>.asc`. See
[`CONTRIBUTING.md`](../CONTRIBUTING.md#key-rotation) for the
retention rule and the cryptographic-transition-statement
requirement.

## Verifying a single file offline

If you already have the team's primary signing key imported:

```sh
gpg --verify pub/<handle>.asc
```

…will verify the **self-signature** on the key (every OpenPGP
key has one — that's how GnuPG knows the key isn't a forgery).
For verifying that the *team* actually published this file
(i.e. cross-checking against the team's signing subkey),
follow the rotation procedure in `CONTRIBUTING.md`.
